# SAGBAL

**移動の仲裁 —— Kimetron Isle の上に重ねる「層（stratum）」です。**

SAGBAL は、物理エンジン Kimetron Isle とアプリケーションのあいだに
挟まる中間層ライブラリです。ユニット同士が同じ場所や通路を取り
合ったとき、**誰が先に通るか・誰が譲るか・行き詰まったらどうする
か** を仲裁し、その顛末をイベントとしてアプリへ返します。

設計上の絶対条件は **「物理の真実はすべて Kimetron が握る」** こと
です。Kimetron は「ここに置けるか」「誰が邪魔をしているか」の
事実だけを返し、「なぜ動けないのか」「どう解決すべきか」の判断は
すべて上の層の仕事です。Kimetron 側に「目的」「優先度」「門」と
いった概念は持ち込みません。

名前の由来: シュメール語の *sag*（前方）+ *bal*（交差する）
——「前方の交差を裁く層」。Kimetron Isle という島の上に積もる
最初の層、という意味も込めています。

## 層の役割分担

```
App（アプリ側の判断）    行き先・優先度・「反対側へは門を通る」
                       という経路の知識 —— 世界の意味はここで決める
SAGBAL（このライブラリ） 行き先の取り合いを検出して順位を付け、
                       負けたユニットに一歩下がらせる。行き詰まりは
                       両方を脇へ退避させ、衝突の繰り返しや停滞は監視
                       してイベントとして通知する
Kimetron Isle          物理の事実だけ：占有・固体・移動の可否・
                       「誰とぶつかったか」
```

事実は上へ、指示は下へ流れます。Kimetron は「目的地」や「門」を
知らなくても動き、App は衝突判定の計算を自分で書かずに済みます。

## 構成

| パス | パッケージ | 役割 |
|------|-----------|------|
| `packages/core` | `@kimetron/core` | Kimetron Isle コアエンジン（同梱 v1.2.0） |
| `packages/dom` | `@kimetron/dom` | DOM レンダラ（同梱） |
| `packages/react` | `@kimetron/react` | React アダプタ（同梱） |
| `packages/sagbal` | `@kimetron/sagbal` | 層の本体 —— 仲裁・目標・stratumイベント |
| `app/` | `sagbal-app` | デモ：ポストを巡るスライム6体——門付きの壁の世界と街路網の迷路（`?maze`）——＋ドラッグ可能なプレイヤー |

## デモ

https://github.com/user-attachments/assets/323f899a-2f8c-4a54-8a07-ae68d2895b3d

- 徘徊者6体が目的地ポストを巡回し、到着すると約3秒滞留。
  動画は街路網の迷路（`?maze=1`）：廊下・9つの辻・袋小路で構成。
  既定の世界は一つだけの門を持つ壁——どちらも経路の知識はApp側が
  持ち、via点の列として層に渡します。
- プレイヤー **P** は手でドラッグ —— 物理の真実は全員に同一。
- イベントログは3色＝3層。`blocked by` はKimetronの生の事実、
  `contention` / `yield` / `deadlock` / `sidestep` / `explodes` /
  `repeat-block` / `no progress` はSAGBALが組み立てた事象、
  `arrived` / `dwells` / `goal` 切替はApp側のライフサイクル。
- 衝突は正直：ユニットは不可視の16角形footprint＋App描画の
  スプライト。Pを建物へ運ぶと、壁は拒否し、街路は通す。
- すれ違いは**右側通行**——行き詰まった2体はそれぞれ自分の右へ
  逸れるので、廊下で対向する流れが自然に上下のレーンへ分かれ
  ます（`Policy.keepSide` で世界ごとに変えられます）。
- 正面衝突も多数決で決まります：スコアに差があれば負けた方だけが
  逸れて勝者が通り、同点なら両方が脇へ退避します（ログでは
  `deadlock → 勝者` と `both sidestep` の違いが見えます）。
- 完全に身動きが取れなくなった徘徊者は周囲へ発信し、近くの仲間が
  押し出されるように散ります（`boxed` → `diffuse`）。混み具合は
  `crowded` / `full` の事実として出ます。
- Pを交通の中へドラッグすると、その移動が意図として登録される
  ので、徘徊者たちは他のユニットと同じように道を譲ります。
- ドラッグは「配置」ジェスチャ（Kimetronはゲームではなく配置
  エンジン）：経路ではなく着地地点が検査される——壁を越えて
  持ち上げて置くことはできるが、壁の中には置けない。

## 開発

```sh
npm install
npm run dev -w sagbal-app   # デモ http://localhost:5173
                            # 街路網の迷路 http://localhost:5173/?maze=1
npm run typecheck           # 全ワークスペース
npm run build -w sagbal-app # プロダクションビルド
npx vitest run              # テスト
```

## 状態

v0.5.0 —— ブロッカー帰属の修正。拒否された一歩が複数の固体
（壁とユニット等）に同時に重なった時、`blocked` は登録順の先頭
（たいてい壁）ではなく、交渉できる相手——登録済みエージェントや
外部意図——を報告する。イベントには全重なりを列挙する
`blockerIds` も付き、`repeat-block` も交渉できる相手を数える。

v0.4.0 —— 行き先の仲裁と譲り合い・経由点・阻害検出と目標切替・
休眠目標のwake・閉路の総意解決（スコア差なら敗者だけが逸れる、
同点なら両方退避）・停滞の監視・ストレス爆発・右側通行に加え、
§5拡散（完全閉塞時に周囲を散らす斥力場）・§8局所密度の事実
（`crowded` / `full`）・外部意図（`setIntent`——ドラッグ中の
プレイヤーも他のユニットと同じように競りに参加）を実装。
